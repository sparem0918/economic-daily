# 경제 데일리 (Economic Daily) - 버핏 에디션

당일 한국 경제 뉴스를 한 페이지에 신문 스타일로 정리해서 보여주는 로컬 웹앱입니다. 워렌 버핏 투자 원칙 체크포인트가 매일 다르게 표시됩니다. PC·모바일 모두 같은 주소로 접속할 수 있습니다.

---

## 실행 방법

이 앱은 두 가지 방식으로 사용할 수 있습니다.

| 방식 | 특징 |
|---|---|
| **A. 로컬 실행** (`run.bat`) | 내 PC에서 실시간 사용. PC가 켜져 있어야 함 |
| **B. GitHub Pages 배포** | 클라우드에서 매시간 자동 빌드. PC 꺼도 됨, 어디서든 접속 |

GitHub Pages 배포 가이드는 `DEPLOY_GITHUB_PAGES.md` 문서를 참고하세요.

## 2. 빠른 실행

1. 이 폴더 전체를 원하는 위치에 둡니다.
2. `run.bat`을 더블클릭합니다.
3. 처음 실행 시 가상환경 생성과 패키지 설치가 자동으로 진행됩니다 (1~2분).
4. 콘솔에 다음과 비슷한 메시지가 뜨면 준비 완료입니다.

```
주소     : http://localhost:5000
로컬망   : http://<PC-IP>:5000  (모바일에서 접속 시 사용)
```

5. PC 브라우저에서 `http://localhost:5000` 로 접속합니다.

---

## 3. 모바일에서 보기

PC와 같은 Wi-Fi 네트워크에서 사용하면 됩니다.

1. PC의 로컬 IP를 확인합니다 (`cmd` → `ipconfig` → IPv4 주소, 예: `192.168.0.10`).
2. 휴대폰 브라우저에서 `http://192.168.0.10:5000` 으로 접속합니다.
3. 방화벽 알림이 뜨면 **사설 네트워크** 허용을 눌러주세요.

홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 4. 주요 기능

| 기능 | 설명 |
|---|---|
| RSS 수집 | 연합뉴스·한국경제·매일경제·조선비즈 다중 피드 병렬 수집 |
| 자동 분류 | 키워드 기반으로 증시 / 금융 / 산업 / IT·테크 / 글로벌 등으로 분류 |
| 키포인트 추출 | 각 뉴스에서 정보량 높은 핵심 문장 1~2개 추출 |
| 헤드라인 선별 | 숫자·임팩트 키워드 점수로 상위 6건 자동 선별 |
| 시장 펄스 | 상승/하락 키워드 빈도로 당일 분위기 시각화 |
| 트렌드 키워드 | 자주 등장한 거시·기업 키워드 표시 |
| 버핏 체크포인트 | MD 파일에서 매일 다른 원칙 1개를 결정론적 시드로 표출 |
| 버핏 태그 | 뉴스마다 관련 버핏 원칙 자동 태깅 |
| 매수 전 질문 | MD의 17번 섹션 질문 자동 표시 |
| 다크모드 | OS 다크모드 설정 자동 반영 |
| 캐시 | 30분 캐시, `/?refresh=1` 또는 R 키로 즉시 갱신 |

## 6. 설정 변경 (config.py)

| 설정 항목 | 의미 | 기본값 |
|---|---|---|
| `RSS_FEEDS` | RSS 피드 목록 (추가·제거 가능) | 10개 피드 |
| `CACHE_TTL_MINUTES` | 캐시 유효 시간(분) | 30 |
| `MAX_NEWS_PER_CATEGORY` | 카테고리당 최대 뉴스 수 | 8 |
| `MAX_HEADLINES` | 헤드라인 최대 개수 | 6 |
| `NEWS_HOURS_WINDOW` | 최근 N시간 뉴스만 표시 | 24 |
| `PORT` | 서버 포트 | 5000 |

피드를 추가하려면 `RSS_FEEDS` 리스트에 다음 형태로 한 줄 추가:

```python
{"name": "매체명", "url": "https://...", "category": "증시"},
```

## 9. 문제 해결

**RSS 수집이 0건일 때**
- 네트워크 연결을 확인하세요.
- 해당 매체가 RSS 구조를 변경했을 수 있습니다. `config.py`에서 해당 피드를 잠시 제거해 보세요.

**모바일에서 접속 안 됨**
- PC와 같은 Wi-Fi 인지 확인.
- Windows 방화벽에서 Python 허용 여부 확인.
- `ipconfig`로 다시 IP 확인.

**한글이 깨질 때**
- BAT 파일은 영문(ASCII) 전용이며 모든 한글은 Python에서 UTF-8로 출력합니다.
- 콘솔이 여전히 깨지면 `chcp 65001` 을 먼저 실행해 보세요.

**포트 5000 충돌**
- `config.py`에서 `PORT = 5001` 등으로 변경.
